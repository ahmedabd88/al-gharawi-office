# مكتب النائب سالم سوادي الغراوي

موقع عربي RTL لمكتب النائب سالم سوادي الغراوي.

**عنوان المكتب:** بغداد، المحمودية، حي البتول  
**الدائرة الانتخابية:** بغداد الكرخ — الدائرة 17

## التشغيل محلياً

```bash
npm install
npm run dev
```

يفتح على: [http://127.0.0.1:43127](http://127.0.0.1:43127)

## الصفحات

- `/` الرئيسية
- `/about` عن المكتب
- `/services` الخدمات
- `/request` تقديم طلب (الاسم الرباعي + واتساب)
- `/contact` التواصل
- `/requests-table` جدول الطلبات الرسمي للطباعة (مكتب)

## نموذج المواطن

في `/request` يدخل المواطن:
1. الاسم الرباعي بالعربية
2. رقم واتساب عراقي (`07XXXXXXXXX`)
3. يُفتح واتساب برسالة جاهزة إلى `07762084894`

الطلبات تُحفظ محلياً على الجهاز وتظهر في `/requests-table` بصيغة «جدول طلبات» الرسمي للطباعة.
