# مكتب النائب سالم سوادي الغراوي

موقع عربي بواجهة RTL لمكتب النائب سالم سوادي الغراوي — صفحة عامة تشمل التعريف، خدمات المكتب، ونموذج التواصل.

Arabic RTL public site for the Office of Representative Salem Sawadi Al-Gharawi (landing, about, services, contact).

## التشغيل محلياً / Run locally

```bash
npm install
npm run dev
```

يفتح الخادم على: [http://127.0.0.1:43127](http://127.0.0.1:43127)

```bash
npm run build
npm start
```

## المحتوى / Content notes

- حقائق عامة مؤكدة من مصادر انتخابية/برلمانية (الاسم الكامل، دائرة بغداد الكرخ 17، انتخابات 2021، عضوية اللجنة القانونية آذار 2022).
- الهاتف والبريد والعنوان وأوقات الاستقبال والسيرة التفصيلية **بانتظار تأكيد المكتب** — لم تُختلق أرقام أو عناوين.

## التقنيات / Stack

Next.js (App Router) · TypeScript · Tailwind CSS · shadcn/ui
