# مكتب النائب سالم سوادي الغراوي

موقع عربي RTL لمكتب النائب سالم سوادي الغراوي.

## التشغيل محلياً

```bash
npm install
npm run dev
```

يفتح على: [http://127.0.0.1:43127](http://127.0.0.1:43127)

## النشر المجاني على Vercel (رابط إنترنت عام)

### 1) ارفع المشروع إلى GitHub
1. ادخل [github.com](https://github.com) وسجّل الدخول.
2. اضغط **New repository**.
3. سمِّه مثلاً: `al-gharawi-office`
4. اتركه Public واضغط **Create repository**.
5. ارفع ملفات المشروع إلى هذا المستودع (من Cursor: Source Control → Publish Branch / Push إلى GitHub).

### 2) اربط المستودع بـ Vercel
1. ادخل [vercel.com/dashboard](https://vercel.com/dashboard)
2. اضغط **Add New… → Project**
3. اختر **Import** لمستودع GitHub `al-gharawi-office`
4. Framework Preset: **Next.js** (يُكتشف تلقائياً)
5. اضغط **Deploy**

### 3) احصل على الرابط
بعد دقائق يظهر رابط مثل:
`https://al-gharawi-office.vercel.app`

هذا رابط عام يعمل من أي متصفح في العالم.

### 4) (اختياري لاحقاً) دومين خاص
من Vercel → Project → **Settings → Domains** أضف نطاقاً اشتريته مثل `algharawi.com`.
