# مكتب النائب سالم سوادي الغراوي

موقع عربي RTL لمكتب النائب سالم سوادي الغراوي.

**عنوان المكتب:** بغداد، المحمودية، حي البتول  
**الدائرة الانتخابية:** بغداد الكرخ — الدائرة 17

## التشغيل محلياً

```bash
cp .env.example .env.local
npm install
npm run dev
```

يفتح على: [http://127.0.0.1:43127](http://127.0.0.1:43127)

## الصفحات العامة

- `/` الرئيسية
- `/about` عن المكتب
- `/services` الخدمات
- `/request` تقديم طلب (الاسم الرباعي + واتساب) — عام
- `/contact` التواصل

## منطقة المكتب الخاصة (مشفّرة / بكلمة مرور)

- دخول: `/office-login`
- جدول الطلبات: `/requests-table` (محمي — يُعاد توجيه الزوار إلى صفحة الدخول)
- كلمة المرور المحلية الافتراضية (للتطوير فقط): انظر `.env.example` → `OFFICE_ADMIN_PASSWORD`
- على Vercel عيّن `OFFICE_ADMIN_PASSWORD` و `OFFICE_SESSION_SECRET` ثم Redeploy

الطلبات من `/request` تُحفظ مشفّرة على الخادم (كتابة فقط للعموم) ويقرأها المكتب بعد الدخول.

## نموذج المواطن

في `/request` يدخل المواطن:
1. الاسم الرباعي بالعربية
2. رقم واتساب عراقي (`07XXXXXXXXX`)
3. يُفتح واتساب برسالة جاهزة إلى `07762084894`
