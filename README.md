# مكتب النائب سالم سوادي الغراوي

موقع عربي RTL لمكتب النائب سالم سوادي الغراوي.

**عنوان المكتب:** بغداد، المحمودية، حي البتول  
**الدائرة الانتخابية:** بغداد الكرخ — الدائرة 17

## التشغيل محلياً

```bash
cp .env.example .env.local
npm install
npm run dev -- --port 43127 --hostname 127.0.0.1
```

يفتح على: [http://127.0.0.1:43127](http://127.0.0.1:43127)

## الصفحات العامة

- `/` الرئيسية
- `/about` عن المكتب
- `/services` الخدمات
- `/request` متابعة الطلب (استعلام بالاسم + واتساب — بدون إنشاء طلب جديد)
- `/contact` التواصل

القائمة العامة لا تعرض روابط المكتب الخاصة. الزائر لا يقدّم طلباً جديداً من الموقع.

## لوحة التحكم الخاصة (كلمة مرور)

| الخطوة | الرابط |
| --- | --- |
| دخول سري | `/office-login` |
| لوحة التحكم بعد الدخول | `/office` |

**كلمة المرور المحلية الافتراضية (تطوير فقط):** `ahmed-office-2026`  
(معرّفة في `.env.example` → `OFFICE_ADMIN_PASSWORD`)

من اللوحة يمكن:
- تعديل نصوص الموقع (الترحيب، الهاتف، العنوان، الدوام، …) وحفظها مشفّرة
- تسجيل طلبات المواطنين وعرضها (العام يستعلم فقط عبر متابعة الطلب)
- كتابة ملاحظات نشر داخلية
- معاينة الموقع العام وتسجيل الخروج

`/requests-table` يعيد التوجيه إلى `/office?section=requests`.

### ضبط كلمة المرور على Vercel

1. Project → Settings → Environment Variables
2. أضف:
   - `OFFICE_ADMIN_PASSWORD` = كلمة مرور قوية خاصة بك
   - `OFFICE_SESSION_SECRET` = نص عشوائي طويل
3. Redeploy

## متابعة الطلب (عام)

في `/request` يدخل المواطن الاسم الرباعي ورقم واتساب مسجّل لدى المكتب لعرض الحالة فقط. لا يُفتح واتساب لتقديم طلب جديد ولا يُحفظ طلب من الصفحة العامة.
